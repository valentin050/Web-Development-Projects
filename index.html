What is Triathlon?

In this page I will show you the information about triathlon!

What is it about?

Triathlon is a multi-sport event that consists of three consecutive disciplines: swimming, cycling, and running.

Disciplines

The three disciplines are typically performed in this order:

  1. Swimming
  2. Cycling
  3. Running

Types of Triathlons

There are several distances, including:

  • Super Sprint: 400m swim, 10km bike, 2.5km run
  • Sprint: 750m swim, 20km bike, 5km run
  • Olympic: 1.5km swim, 40km bike, 10km run
  • Half Ironman: 1.9km swim, 90km bike, 21.1km run
  • Ironman: 3.8km swim, 180km bike, 42.2km run

The ones I like the most are the Olympic and sprint distances.
